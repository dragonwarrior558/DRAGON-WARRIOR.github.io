# My Personal Blog — $0 Website

## Files
- `index.html` — website structure and content
- `style.css` — design/responsive styling
- `script.js` — mobile menu, post popups and year

## Customize
Open `index.html` and replace:
- "MY BLOG" with your site name
- About text
- Post titles/descriptions
- Instagram and YouTube links
- `hello@example.com` with your email

## Publish free with GitHub Pages
1. Create a free GitHub account at github.com.
2. Create a new **public** repository named `yourusername.github.io`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open the repository's Settings → Pages.
5. Select deployment from the `main` branch/root folder.
6. Your free site will appear at `https://yourusername.github.io/`.

No paid hosting or domain is required.
